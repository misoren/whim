#### Illustrations
The snippets offer several new illustration SVGs as `whim-svg-[name](../screenshots/snippets/text).css`. These files can be somewhat large. These snippets provide note classes for stamp BG, borders, horizontal rule, callout background, and masks.

In additional, there are "bg-illustration" snippets that can be activated alongside the first set to set the app background to one of the illustrations. I've also provided a set of these for the illustrations included within the theme.

There are also several `whim-svg-icon-bg-[name](../screenshots/snippets/text).css` files that set the app background to a pattern based on one of the icons included in the theme.
